# Reserva Operador Turistico

Prototipo web para reservar cupos en transporte turístico (catamarán, lancha, kayak). Front-end con Vite + React, sin backend y con datos de ejemplo.

## Correr en local

```bash
npm install
npm run dev
```

Abre la URL que muestra la terminal (normalmente http://localhost:5173).

## Publicar

Pensado para deploy directo en Vercel desde un repositorio de GitHub. Vercel detecta Vite solo: comando de build `npm run build`, carpeta de salida `dist`.

## Documentos

Arquitectura, historias de usuario y boceto en `docs/`. Reglas del proyecto en `CLAUDE.md`.
